Kiosk 
java 기반의 콘솔 키오스크 코딩.

해당 코딩은 기능 단계를 나누어 발전시켰습니다.

1.프로젝트 개요
자바 객체지향 설계를 위한 점진적 단계 프로젝트
각 단계를 통해 객체지향,캡슐화, 리스트를 활용했다.

2.파일구조
Main -> 프로그램 진행
MenuItem -> 개별 메뉴 아이템(메뉴이름, 가격, 설명)
Kiosk -> 전체 키오스크를 관리
Menu -> 카테고리, List<MenuItem>관리
README -> 프로젝트 사용 설명서
3.제공하는 기능
각 카테고리별 메뉴 출력
카테고리 선택 -> 선택한 메뉴 출력
0 입력 시 종료 및 뒤로가기 출력

4.사용방법
콘솔 키오스크 코딩으로 출력되는 출력물을 보고
숫자를 입력하면 이에 맞는 출력물이 출력
뒤로가거나 종료를 원한다면 0을 입력

5. 각 단계별 점진적으로 진화하는 프로젝트
Lv1: 한 클래스에서 모든 기능 및 출력을 구현
Lv2: MenuItem 클래스 분리, 객체지향의 1단계 (메뉴아이템을 객체로 관리)
Lv3: Kiosk클래스 메뉴아이템 리스트 분리, 기능 분리
Lv4: Menu클래스 추가, 카테고리별로 저장 원하는 리스트만 출력하기 기능 구현
Lv5: 캡슐화 적용 필드변수 private처리 / getter 통해 접근하기 구현
